# COE_databaseManager
A database viewing and management tool designed for use by ERAU faculty

Requires :  
Java  
Maven  
node.js (javascript and npm)  
MySQL (with a database)  

To start :  
go into `/backend`  
run `mvn spring-boot:run`  
go into `/frontend`  
if this is your first time, run `npm install`  
run `npm start`
